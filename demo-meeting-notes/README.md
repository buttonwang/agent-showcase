# Demo 03:会议纪要管理\n\n> 业务助手智能体生成的参考 Demo。双击 `index.html` 即可在浏览器中打开使用。\n\n## 这是什么\n\n团队会议纪要管理工具,写会议笔记、按状态(待开始/进行中/已完成/已搁置)看板跟踪行动项。\n\n## 主要功能\n\n- 5 个视图:总览 / 会议列表 / 纪要详情 / 行动项看板 / 设置\n- 会议 CRUD(标题/时间/地点/类型/状态/参会人/纪要)\n- 行动项 CRUD(标题/负责人/截止/优先级/状态)\n- 行动项看板拖拽(4 列状态)\n- 5 种会议类型:周会/月会/复盘/客户会/1对1\n- 3 种优先级:高/中/低\n\n## 怎么用\n\n1. 双击 `index.html`,在 Chrome / Edge / Firefox 等现代浏览器中打开\n2. 左侧是主导航,点击切换模块\n3. 顶部月亮/太阳图标可以切换深色/浅色主题\n4. 所有数据保存在浏览器 `localStorage`,刷新不丢失\n5. 设置页可以"导出数据"为 JSON,做备份\n\n## 技术栈\n\n- Tailwind CSS(CDN)\n- Alpine.js 3(CDN)\n- lucide 图标(CDN)\n- localStorage 持久化\n\n## 设计参考\n\n- 主色:蓝色 `hsl(221.2 83.2% 53.3%)`\n- 字体:Inter\n- 圆角:8px\n- 风格:Vercel / shadcn UI\n\n## 与 Skill 的关系\n\n本 Demo 是 `business-assistant-agent` Skill 的内置参考。学员可以在自己的 Codex 中描述类似的业务需求,Skill 会基于这个 Demo 的模式生成新的产品。\n\n## 数据本地化\n\n- 数据存储键:`C:\Users\pc\Documents\Codex\2026-06-08\files-mentioned-by-the-user-prd\outputs\demo-meeting-notes__data_v1`\n- 存储位置:浏览器 `localStorage`\n- 备份方式:设置页 → 导出数据\n
