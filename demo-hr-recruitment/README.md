# Demo 02:HR 招聘后台\n\n> 业务助手智能体生成的参考 Demo。双击 `index.html` 即可在浏览器中打开使用。\n\n## 这是什么\n\nHR 招聘管理后台,覆盖发布招聘需求、跟踪候选人管道(简历筛选→HR 面试→业务面试→管理终面→已发 offer)、记录每轮面试评价、统计新员工入职 30 天满意度。\n\n## 主要功能\n\n- 5 个模块:招聘概览 / 招聘需求 / 候选人管道 / 面试记录 / 入职调查\n- 招聘漏斗(数据可视化)\n- 候选人看板拖拽(5 列状态机)\n- 面试评分 1-5 星 + 评价\n- 入职满意度卡片 CRUD(3 维度评分)\n- 5 种状态色:成功/警告/危险/进行中/默认\n\n## 怎么用\n\n1. 双击 `index.html`,在 Chrome / Edge / Firefox 等现代浏览器中打开\n2. 左侧是主导航,点击切换模块\n3. 顶部月亮/太阳图标可以切换深色/浅色主题\n4. 所有数据保存在浏览器 `localStorage`,刷新不丢失\n5. 设置页可以"导出数据"为 JSON,做备份\n\n## 技术栈\n\n- Tailwind CSS(CDN)\n- Alpine.js 3(CDN)\n- lucide 图标(CDN)\n- localStorage 持久化\n\n## 设计参考\n\n- 主色:蓝色 `hsl(221.2 83.2% 53.3%)`\n- 字体:Inter\n- 圆角:8px\n- 风格:Vercel / shadcn UI\n\n## 与 Skill 的关系\n\n本 Demo 是 `business-assistant-agent` Skill 的内置参考。学员可以在自己的 Codex 中描述类似的业务需求,Skill 会基于这个 Demo 的模式生成新的产品。\n\n## 数据本地化\n\n- 数据存储键:`C:\Users\pc\Documents\Codex\2026-06-08\files-mentioned-by-the-user-prd\outputs\demo-hr-recruitment__data_v1`\n- 存储位置:浏览器 `localStorage`\n- 备份方式:设置页 → 导出数据\n
